# 传统乐谱滚动独立复核

日期：2026-10-04。审查对象：当前工作区中的传统纵向滚动改动。

## 结论

本轮没有发现可确认的阻塞问题。实现符合修订后的方案：实际换行后，即使下一行已经完整可见，也会根据阅读带规则平缓归位；完成后停止移动。保留完整原谱排版，反复和 Loop 使用原有返回定位分支。

本轮成功执行了原生 rAF 测试，补充了实现方执行记录中尚未完成的新纵向原生运动验证。结论限于下面实际运行的场景，不代表所有谱例、浏览器或硬件已经验收。

## 代码审查

- 系统几何通过实际 OSMD system 身份建立索引，转换为容器 CSS 坐标；策略、几何转换、时长估算与帧调度分别承担独立职责。
- 当前显示位置使用 painted 快照与匹配的正式事件，避免用预取迭代器提前触发换行。
- 阅读带为 25%～35%，中心 30%；完整系统可读性与滚动边界优先。
- Wait 默认 650ms；Follow / Realtime 使用本次系统实际时值和有效速度，时长为预计时间的 20%，限制为 400～1200ms。
- 同系统音符不重启动画；连续换行从实际位置接管。暂停、人工滚动、重排及销毁取消旧帧。
- 本次也调整了重排时 painted 位置、反馈锚点和 scrollTop 的保留，因此专门重跑了共用显示与横向回归。

## 原生动画实测

- 测试视口高度 697 CSS px；新系统原本已完整可见。
- 系统顶部从约 444.5px 平缓移到约 209.3px，即视口高度的约 30%。
- 目标 scrollTop 约 235.4px，实际约 235.2px，误差小于 1px。
- Realtime 100% 的本行估计时长约 10.67 秒，动画 D 为 1200ms；约 1173ms 时进入目标 1px 范围，随后完成归位。
- 233 个关联原生采样覆盖移动与收敛后的状态。测试确认无超过容差的反向移动或目标越界，后续音符不改截止时间，静止后停止请求帧。
- Realtime 200% 的 D 约 1066.67ms；Follow 200% 使用相同时长；Wait 在 50% 和 200% 下都使用 650ms。

证据：[原生测试摘要与采样](validation/traditional-review-native.json)、[显示回归回执](validation/traditional-review-score-display.txt)。本轮命令完整输出位于本地忽略目录 `.cache/review-traditional-check.txt`。
